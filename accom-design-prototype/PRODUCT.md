# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Delegated by the brief: dependency-free HTML, CSS and JavaScript served by Node, chosen to deliver the complete single-page prototype without a package install or production platform work.

## Users

Students comparing UK accommodation, especially international first-year students, mobile-heavy UK undergraduates, postgraduates, parents or guarantors, and students with accessibility requirements.

## Product Purpose

Accom by Emlen helps students understand accommodation options and ask for human assistance. This prototype proves a single property page can make room choice, cost, location, inclusions, policy uncertainty and the enquiry next step clearer than a generic directory page.

## Positioning

The page is an assistance-led decision surface: Accom helps students evaluate and enquire, while payment and any confirmed booking remain with the accommodation provider.

## Operating Context

Prospective students compare room types, tenancy options, total cost, included bills, commute and policy conditions before sending a property-specific enquiry. Many do this remotely and on mobile.

## Capabilities and Constraints

This evaluation covers one iQ Kingston property-detail page. Local demo state powers gallery, room comparison, saved state and enquiry confirmation. There is no backend, authentication, payment, live availability or confirmed booking. Dynamic commercial values remain labelled illustrative.

## Brand Commitments

Use the name Accom by Emlen, primary red `#ED2024`, Bricolage Grotesque headings, Montserrat body, an immersive gallery, a 75:25 desktop content/CTA split, sticky section navigation and selective glass surfaces.

## Evidence on Hand

Official iQ property information, Accom's public positioning, WCAG 2.2, independent accommodation UX research, individual app/reddit reports with explicit evidence limits, a local Amber audit, and four generated illustrative gallery images. No authorised iQ/Amber photography, verified property-specific Accom offers, live prices, accessibility schedule, or current cancellation terms are available.

## Product Principles

- Decision facts before promotion.
- Exact status language instead of false certainty.
- Compare without making students remember.
- Ask for help without implying a booking.
- Unknowns are visible and actionable.

## Accessibility & Inclusion

Target WCAG 2.2 AA. The property-level access details are not verified; the interface must say so and provide a specific accessibility enquiry route.
